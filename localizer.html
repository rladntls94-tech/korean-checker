이벤트 페이지 다국어 치환 툴

사용 순서
  1. 원본 소스 붙여넣기 → [한국어 추출]
  2. 번역 테이블 탭 → [엑셀 템플릿 받기] → 번역가에게 전달
  3. 번역가는 언어 열만 입력
  4. 받은 표를 [번역된 표 불러오기]로 적용
  5. 결과 생성 탭 → 언어를 바꿔가며 [HTML 생성]
